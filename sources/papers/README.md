# Paper sources

Place paper PDFs here. Their titles and abstracts are extracted automatically.

For precise metadata, add a same-named JSON file beside any PDF. Example:

```json
{
  "title": "Paper title",
  "authors": ["Coauthor One", "Coauthor Two"],
  "category": "Published and Accepted Papers",
  "status": "Published",
  "venue": "Journal Name",
  "year": "2026",
  "links": {"Paper": "https://doi.org/...", "Code": "https://github.com/..."}
}
```
